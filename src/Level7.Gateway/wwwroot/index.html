1 · Drive traffic

Fires at /api/resource through the gateway. Watch the source chip on each row: redis = normal, local_fallback / fail_open / fail_closed = degraded.

2 · Simulate a Redis outage

Makes the gateway's Redis call throw inside the same Polly pipeline a real outage would hit — so the circuit breaker trips for real. After ~3 failed calls in 10s the breaker opens; while open, decisions degrade instantly (no Redis timeout per request). Turn this off and fire a few more requests once the 5s cool-off passes to watch it recover.

3 · Degrade mode (what happens while down)

Fail Open — allow everything (availability over protection).
Fail Closed — reject everything (protection over availability).
Local Fallback — degrade to an in-process Level-1 limiter (graceful; the roadmap's payoff).
Change this while outage is ON to see the same failure handled 3 different ways.
